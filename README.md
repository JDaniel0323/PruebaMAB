Este es un sistema básico de gestión de productos (CRUD) desarrollado para la prueba técnica. La aplicación permite realizar las operaciones fundamentales: Agregar, Ver, Actualizar y Eliminar productos en una base de datos mysql.

## Tecnologías Utilizadas

- **Frontend:** HTML5 y CSS3.
- **Backend:** PHP.
- **Base de Datos:** MySQL.

## Características

- **Listado de productos:** Visualización de todos los registros en una tabla.
- **Creación:** Formulario para añadir nuevos productos (Nombre, Precio y stock).
- **Edición:** Modificación de datos existentes en BD.
- **Eliminación:** Borrado de registros.
- **Validaciones:** Control básico de campos vacíos y tipos de datos.
