Este es un sistema básico de gestión de universidades en base a una API, desarrollado para la segunda prueba técnica.

## Tecnologías Utilizadas

- **Frontend:** HTML5 y CSS3.
- **Backend:** PHP.
- **Base de Datos:** MySQL.
